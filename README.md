One Day on Earth — Friday 20 November 2026 in a single image: 30 verified stories from one rotation of the planet, read westward as the day travelled. A sun-path map with numbered dispatch pins, twelve dispatch postcards told in full, a three-leg logbook of briefs, and a cutting-room box that holds Thursday's news back on date discipline. Every story happened, or was first reported, on Friday 20 November 2026. The page content lives in `data.json`; `render.py` draws it; `main.py` ships the finished `entry.png`.

## Run it

```sh
python3 main.py
```

(Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.png` is written; it defaults to `/output`. To re-render the page itself: `python3 render.py`.)
